Неделя 1 — Введение и основы

Темы: алгоритм, псевдокод, сложность (время/память), Big-O, простые примеры.

Упражнения: реализовать и проанализировать линейный и бинарный поиск.

Практика: 3 простые задачи (поиск, суммирование).

Инструменты: настроить окружение (VSCode/PyCharm), GitHub.

Неделя 2 — Массивы и строки

Темы: операции с массивами/строками, слайсы, in-place модификации.

Упражнения: переворот массива, поиск подстроки, частотный подсчёт символов.

Практика: 4–5 задач со строками и массивами.

Неделя 3 — Стеки, очереди, дек

Темы: LIFO/FIFO, реализация через массивы/связаные списки, применение (парсинг, backtracking).

Упражнения: проверка скобочной последовательности, реализация очереди через два стека.

Неделя 4 — Связанные списки

Темы: односвязный/двусвязный список, операции вставки/удаления, указатели/ссылки.

Упражнения: удаление k-го с конца, реверс списка.

Неделя 5 — Рекурсия и разбиение задач

Темы: рекурсия, стек вызовов, мемоизация.

Упражнения: факториал, фибоначчи (рекурсивно, с мемоизацией, итеративно), backtracking (генерация подмножеств).

Неделя 6 — Сортировки и анализ

Темы: пузырёк/вставками/выбором (для понимания), быстрая сортировка, сортировка слиянием, пирамидальная сортировка; стабильность сортировок.

Упражнения: реализовать merge sort и quicksort, сравнить по времени на больших массивах.


Неделя 7 — Хэш-таблицы (словари)

Темы: хеширование, коллизии, load factor, применение.

Упражнения: реализовать простую хеш-таблицу на языке (или использовать встроенную) и решать задачи на частоту элементов.

Неделя 8 — Деревья (бинарные деревья)

Темы: бинарное дерево, обходы (in/pre/post), высота, сбалансированные и несбалансированные деревья.

Упражнения: обходы, поиск глубины, проверка сбалансированности.

Неделя 9 — Двоичное дерево поиска (BST) и дерево отрезков/фенвик (опционально)

Темы: вставка/удаление в BST, свойства. Fenwick/Segment Tree (основы, если надо).

Упражнения: реализовать BST; простые задачи на диапазонные запросы (Fenwick).

Неделя 10 — Кучи (heaps)

Темы: реализация кучи, priority queue, сортировка через кучу, top-k задачи.

Упражнения: найти k-й элемент, merge k sorted lists.

Неделя 11 — Графы: представления и обходы

Темы: матрица смежности vs список смежности, BFS, DFS, ориентированные/неориентированные графы.

Упражнения: реализация BFS/DFS, связные компоненты, кратчайший путь в невзвешенном графе.

Неделя 12 — Графы: алгоритмы кратчайшего пути и MST

Темы: Dijkstra, Bellman-Ford (основная идея), алгоритмы MST: Kruskal, Prim.

Упражнения: реализовать Dijkstra (через priority queue), MST на простом графе.



Неделя 13 — Динамическое программирование (DP)

Темы: подход «разбей на подзадачи», таблицы/мемоизация, типичные шаблоны (knapsack, LIS, DP по состояниям).

Упражнения: Fibonacci DP, Knapsack 0/1, Longest Increasing Subsequence, DP на строках (LCS, edit distance).

Неделя 14 — Жадные алгоритмы, приблизительные алгоритмы

Темы: критерии корректности жадных решений, примеры (interval scheduling, Huffman).

Упражнения: задачи на жадные стратегии, сравнение с DP.

Неделя 15 — Параллельность, асинхронность, практики разработки

Темы: потоки/процессы, async/await (язык-зависимо), проблемы гонок, блокировки, основы конкурентности.

Технологии: основы Docker, CI (GitHub Actions), мониторинг (очень поверхностно).

Упражнения: написать простую многопоточную программу, контейнеризировать приложение.

Неделя 16 — Итоговый проект и подготовка к собеседованиям

Проект: реализовать одно из предложенных (см. ниже) и запушить на GitHub с README + тестами.

Подготовка: ревью решений, 10–15 задач из разных тем для закрепления.

Финальная проверка: список знаний/список задач, которые ты должен уметь решать.



Проекты (капстоун)

Выбери 1–2 проекта, каждый занимает 1–3 недели:

Алго-визуализатор — web-интерфейс, который визуализирует сортировки, BFS/DFS, Dijkstra. Технологии: JavaScript/React или Python + визуализация.

CLI-инструмент для анализа логов — чтение больших файлов, подсчёт частот, top-k, использование потоковой обработки, юнит-тесты.

Сервис “ToDo” с поиском и фильтрацией — реализовать API (REST), бэкенд с БД, пагинация, простая аутентификация, unit/integration тесты, Dockerfile.

Решатель задач (кодовый бот) — парсер входных данных, выбор оптимального алгоритма (например, knapsack + greedy fallback), тесты, нагрузочное тестирование.

Каждый проект: README с описанием сложности, выбранных структур и компромиссов.
